# idex-Blood

เว็บให้ความรู้และคัดกรองอาการไข้เลือดออกสำหรับผู้ใช้ทั่วไป รองรับการเผยแพร่แบบ static บน Netlify

## ฟีเจอร์

- บทความให้ความรู้ 5 เรื่องเกี่ยวกับยุงลาย อาการไข้เลือดออก ระยะวิกฤต การใช้ยา และการกำจัดแหล่งเพาะพันธุ์
- แบบประเมินอาการเบื้องต้น พร้อมคำแนะนำตามระดับความเสี่ยง
- เครื่องคำนวณขนาดพาราเซตามอลตามน้ำหนัก
- เช็กลิสต์ตรวจจุดเสี่ยงยุงลายในบ้าน
- ฟอร์มแจ้งจุดเสี่ยงในชุมชนผ่าน Netlify Forms
- เข้าสู่ระบบด้วย Firebase Authentication พร้อม Local Session สำรอง

## โครงสร้างหลัก

- `index.html` — หน้าแรกและเครื่องมือโต้ตอบ
- `1.*.html` ถึง `5.*.html` — บทความแต่ละเรื่อง
- `login.html`, `logout.html` — การเข้าสู่ระบบและออกจากระบบ
- `assets/css/style.css` — รูปแบบหน้าตาและการจัดวาง
- `assets/js/assessment.js` — แบบประเมิน เครื่องคำนวณ เช็กลิสต์ และฟอร์มรายงาน
- `assets/js/auth.js` — การยืนยันตัวตนและเมนูผู้ใช้
- `รูป/`, `assets/images/` — รูปประกอบ
- `netlify.toml`, `_redirects` — การเผยแพร่ เส้นทาง และส่วนหัวความปลอดภัย
- `__forms.html` — แบบฟอร์มที่ Netlify ใช้ตรวจพบฟิลด์ตอน build

## เปิดดูในเครื่อง

เปิดผ่านเว็บเซิร์ฟเวอร์ static เช่น Netlify CLI (`netlify dev`) หรือ HTTP server ทั่วไป เพื่อให้ ES modules และ Firebase ทำงานได้ถูกต้อง
